# v13.4.3 — honest observe label, layer activation, audit hardening

*Released 2026-07-25. 23 commits since v13.4.2; 54 files, +3,244 / −293.*

## Headline: the cron audit is labelled `replay`, not `mock`

The nightly audit re-feeds REAL recorded DB traces (`pipeline_traces` / `agent_runs`)
through the pipeline. It was labelled `mock` — i.e. real recorded events read as
*simulated*. This release introduces a distinct, self-describing source value:

- **`replay`** — real RECORDED events, batch-replayed (what the cron does).
- **`inject`** — real events fed LIVE by an orchestrator (unchanged, stays pure-live).
- `mock` (simulated) and `ebpf` (kernel) unchanged.

Live and replayed evidence are never conflated in the field a compliance reader consumes.
`layers.observe_note` additionally discloses that liveness is conveyed by the preserved
per-event timestamps, not wall-clock. Compliance evidence now **threads the real source**
(helper + explicit param) instead of hardcoded strings — pinned by a test asserting
compliance emits *what the tracer emits*, for every source, across all four exports.

## Layer activation (each honestly scoped)

- **L1 observe** — honest 3-way/4-way source taxonomy + tested cross-platform inject path.
  eBPF remains implemented-but-not-deployed.
- **L2 policy** — builtin↔Rego **parity gate in CI** (OPA v1.18.2, `REQUIRE_PARITY_OPA=1`),
  four dangerous-command divergences closed, then full reconciliation to **zero divergences
  on the corpus**. Production still decides with the built-in engine; the Rego flip stays an
  operator decision.
- **L3 verify** — per-event formal verification: 4-way verdict
  (VERIFIED / REFUTED / ABSTAIN / TIMEOUT), selective + deterministically sampled +
  latency-budgeted, recorded into the HMAC chain. Synchronous by default (Z3 is not
  thread-safe); async is opt-in via an injected ProcessPoolExecutor. Sound on a bounded
  fragment — ABSTAIN outside it, never a false VERIFIED. No production producer attaches
  `formal_artifact` yet.
- **L4 comply** — the decorative Z3 step **removed**; genuine semantic encoder as default
  when `sentence-transformers` is installed, with measured calibration.
  `ZKSNMProtocol` → `ThresholdNonMembershipProtocol` (back-compat alias kept; the
  certificate wire identifier `"ZK-SNM"` deliberately unchanged — it is inside the
  hashed/HMAC'd payload).
- **L5 attest** — at-rest **PKCS#8 passphrase encryption** for the device key (fail-loud
  load, transparent raw→encrypted upgrade) + an **Ed25519 signature over the chain head**
  for public verifiability (`verify_head_signature`, no HMAC secret needed). Neither path is
  wired into a deployed export yet.
- **L6 offline** — SyncEngine validated against **real PostgreSQL in CI** (HMAC-exact rows,
  idempotent `ON CONFLICT`), plus the `guard_events` DDL.
- **L4/L5/L6 remain demo-only by enforced invariant** (`test_layer_wiring.py` keeps them out
  of the production import graph).

## Upgrade note

No API breakage. The visible change is the audit JSON's `layers.observe` value
(`mock` → `replay`) plus the new `layers.observe_note`, and compliance L1 evidence strings
now naming the actual source. Any downstream consumer asserting `observe == "mock"` for the
cron must be updated.
